# **Estructura Datos**



## **Arreglos Bidimensionales** 



**Concepto**

Los arreglos bidimensionales son una forma de organizar datos en filas y columnas, creando una estructura de tabla

Cada elemento en un arreglo bidimensional tiene dos

Índices: uno para la fila y otro para la columna. Se utiliza cuando necesitamos organizar información relacionada en dos dimensiones



**¿Cómo funciona?** 

Cada elemento de la matriz se denomina celda y se puede acceder a él mediante sus índices de fila y columna.

• Índices base cero: la numeración de las filas y columnas comienza en el número 0.

• Acceso a datos. Para leer o modificar un dato especifico, escribes el nombre del arreglo seguido de ambas posiciones, por ejempla matriz(fila||columna)



**Características:**

* Estructura de dos índices.
* Índices basadas en cero.
* Implementación con listas anidadas.
* Flexibilidad de tipos de datos.
* Uso de librerías especializadas.
* Recorrido con ciclos anidados**.**



**Operaciones Principales:**

* Arreglos con Listas Anidadas (NATIVO):

&#x20;  Representan una matriz básica donde cada elemento de la lista principal es una fila.

* Arreglos con NumPy: Para operaciones matemáticas avanzadas, manipulación eficiente de datos y matrices de tamaño fijo.
